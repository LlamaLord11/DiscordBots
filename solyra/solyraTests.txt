SØLYRA CENTRAL BANK — BOT TEST PLAN
=====================================


SETUP — RUN THESE FIRST
------------------------
1.  Start the bot and confirm it comes online with no errors in the console
2.  Confirm the voice channel tracker updates to: 🏦 Bank Total: $0.00
3.  Confirm the audit log channel receives no unexpected alerts
4.  Confirm solyra.db is created in the project directory


ACCOUNT CREATION — /account create
------------------------------------
5.  Create an account as a regular member — confirm account name format is {ign} 00001
6.  Create a second account with a different IGN — confirm ID is 00002
7.  Try creating an account with an IGN under 3 characters — confirm error
8.  Try creating an account with an IGN over 16 characters — confirm error
9.  Try creating an account with special characters in IGN (e.g. Steve!) — confirm error
10. Confirm house account 00000 exists in the DB:
    SELECT * FROM accounts WHERE account_id = 0;


BALANCE — /bal
---------------

    no reserved amount, status Active
12. Confirm account 00000 does not appear in your autocomplete as a regular member


DEPOSIT — /deposit
-------------------
13. Submit a deposit of 100 (whole integer) with a valid image — confirm ticket channel
    created, Accounting pinged, embed shows $100.00
14. Submit a deposit of 50.50 — confirm embed shows $50.50
15. Try depositing 10.123 — confirm rejected before ticket is created
16. Try attaching a .pdf file — confirm rejected before ticket is created
17. Try attaching a .txt file — confirm rejected before ticket is created
18. Try a .png file — confirm accepted
19. Approve the $100.00 deposit as Accounting — confirm balance updates to $100.00,
    ticket deleted, DM received by the depositor
20. Deny the $50.50 deposit with a reason — confirm ticket deleted, DM received with reason
21. Submit another deposit and hit Close — confirm ticket deleted, transaction remains
    pending in DB, no DM sent
22. Submit a deposit on a frozen account (freeze it first) — confirm error before ticket
    is created
23. Restart the bot with an open deposit ticket — confirm view re-attaches and buttons
    still work
